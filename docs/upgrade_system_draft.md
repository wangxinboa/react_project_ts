# 境界体系

## 1. 初始阶段

生命力：1 ~ 5  
类型：base

灵性：1 ~ 5  
类型：base

生命力 4、灵性 4：普通凡人。

生命力低于 4：体质偏弱、容易疲劳、恢复慢。  
灵性低于 4：感知迟钝、精神不集中、学习灵性知识困难。

生命力 5：普通人的优秀体质。  
灵性 5：普通人的优秀感知和精神。  
生命力 5、灵性 5：凡人上限。

此阶段没有衍生属性：

```text
气血上限：0
武道意志：0
精神力上限：0
灵性法术容量上限：0
法力上限：0
```

---

## 2. 初步接触职业阶段

生命力：5 ~ 10  
灵性：5 ~ 10

属性只提升几个点，但表现是指数级提升。这个阶段仍然可能被人数堆死，只是从“普通人”变成“有潜力的人”。

这一阶段开始开发自身潜力，并根据资源分配方向，逐渐形成职业概念。

### 2.1 [气血上限]

类型：derived。

解锁方式：生命力 > 5，自动显化。未解锁时为 0。

公式：

```text
气血上限 = 3 × max(0, 生命力 - 5)
```

本阶段范围：

```text
生命力 5 ~ 10
气血上限 0 ~ 15
```

描述：

碳基生物的生命力提升到一定阶段后，再经过锻炼自然产生的肉身能量。

气血上限不是独立训练出来的，而是生命力达到门槛后自然显化。

气血上限需要灵性、武道意志或精神力上限控制。

类型：derived。

解锁方式：气血上限 > 0 后自动衍生。

气血控制上限：

```text
气血控制上限 = 灵性 + 武道意志 + 0.3 × 精神力上限
```

本阶段范围：

```text
气血控制上限约 5 ~ 17.55
```

超出的气血：

类型：derived。

解锁方式：气血上限 > 0 后自动衍生。

```text
气血失控 = max(0, 气血上限 - 气血控制上限)
```

气血失控效果：

```text
每小时生命力 - 气血失控 × 0.2
每小时灵性 - 气血失控 × 0.1
```

### 2.2 [武道意志]

类型：derived。

解锁方式：生命力 ≥ 6、灵性 ≥ 6，并完成武学学习或相关事件。未解锁时为 0。

公式：

```text
武道意志 = 0.6 × max(0, 生命力 - 5) + 0.4 × max(0, 灵性 - 5)
```

本阶段范围：

```text
武道意志 0 ~ 5
```

描述：

学习武学之后，灵性以武道为显化方向，结合气血上限，初步衍生出的精神对物质的干涉。

武道意志需要主动学习或事件解锁，不会自然出现。

对灵性的占据：

```text
武道意志占用 = 0.5 × 武道意志
```

本阶段占用范围：

```text
灵性占用 0 ~ 2.5
```

对气血的作用：

```text
气血控制上限加值 = 武道意志
气血上限修正 = 武道意志 × 2
```

武道意志越强，可以控制的气血上限越多，可以承载的气血上限也越高。

### 2.3 [精神力上限]

类型：derived。

解锁方式：灵性 > 5，自动显化。未解锁时为 0。

公式：

```text
精神力上限 = 1.5 × max(0, 灵性 - 5) + 0.2 × max(0, 生命力 - 5)
```

本阶段范围：

```text
精神力上限 0 ~ 8.5
```

描述：

不断对自身灵性进行探索，结合自身的生命力，再经过锻炼自然产生的精神力上限量。

精神力上限不占据灵性。

### 2.4 [灵性法术容量上限]

类型：derived。

解锁方式：灵性 ≥ 6，并完成法术学习或相关事件。未解锁时为 0。

公式：

```text
灵性法术容量上限 = 0.8 × max(0, 灵性 - 5)
```

本阶段范围：

```text
灵性法术容量上限 0 ~ 4
```

描述：

使用灵性对外界世界的观想和刻画，用于存放技能，可以理解为法术技能背包的容量。

对灵性的占据：

```text
法术容量占用 = 1.0 × 灵性法术容量上限
```

本阶段占用范围：

```text
灵性占用 0 ~ 4
```

### 2.5 [法力上限]

类型：derived。

解锁方式：生命力 ≥ 6、灵性 ≥ 6，并完成法力循环学习或相关事件。未解锁时为 0。

公式：

```text
法力上限 = 0.8 × max(0, 生命力 - 5) + 0.4 × max(0, 灵性 - 5)
```

本阶段范围：

```text
法力上限 0 ~ 6
```

描述：

对生命力进行转化后形成的施法资源。

法力上限不直接等于生命力，但会占据一部分生命力。

对生命力的占据：

```text
法力占用 = 0.5 × 法力上限
```

本阶段占用范围：

```text
生命力占用 0 ~ 3
```

### 2.6 本阶段资源占用

类型：derived。

解锁方式：相关资源属性存在后自动衍生。

```text
灵性占用 = 武道意志占用 + 法术容量占用
灵性占用 = 0.5 × 武道意志 + 1.0 × 灵性法术容量上限
```

本阶段范围：

```text
灵性占用 0 ~ 6.5
```

```text
生命力占用 = 法力占用
生命力占用 = 0.5 × 法力上限
```

本阶段范围：

```text
生命力占用 0 ~ 3
```

剩余资源：

```text
灵性余量 = 灵性 - 灵性占用
生命力余量 = 生命力 - 生命力占用
```

### 2.7 本阶段职业方向

职业由属性组合与占用关系形成，不是独立类型。

武者：

```text
气血上限 > 0
武道意志 > 0
灵性主要被武道意志占用
```

法师：

```text
灵性法术容量上限 > 0
法力上限 > 0
灵性被法术容量占用
生命力被法力占用
```

两者可以兼修，兼修时占用会叠加。
